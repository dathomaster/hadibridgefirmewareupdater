Need help?

Can't use Chrome? Drag and drop instead
  1. Download the firmware file (about 220 KB).
  2. Unplug the board, hold BOOT, plug it into the computer and let go. A drive named RP2350 appears.
  3. Drag the downloaded file onto that drive. It copies for a second, the drive disappears, and the board restarts by itself.
"RP2350 Boot" isn't in the list

The board isn't in BOOT mode yet. Unplug it, hold BOOT before the cable goes in, and keep holding until it's plugged in. Some USB-C cables only carry power: if it still doesn't show up, try another cable or port.

Could this break the board?

No. The part of the chip that loads firmware is built in and can't be erased, so you can always start again at step 1. The page also reads the firmware back after writing it to check it was saved correctly.

Which board is this for?

The Waveshare RP2350-USB-A (33 × 17.5 mm, one USB-C and one USB-A port). Other RP2350 boards will accept the file but won't work as a bridge, because the HADI port is the USB-A connector.
